# Концепции UI-макетов для MindSpark

## 1. Общие принципы дизайна

### 1.1 Визуальный стиль
- Современный минималистичный дизайн
- Чистые линии и достаточное пространство между элементами
- Использование фирменных цветов #6366F1 и #10B981
- Легкие тени для создания глубины
- Плавные анимации при взаимодействии

### 1.2 Адаптивность
- Дизайн адаптируется под мобильные устройства, планшеты и десктоп
- Использование гибкой сетки с 8px базовой сеткой
- Приоритет мобильного дизайна (mobile-first approach)

## 2. Ключевые экраны

### 2.1 Главный экран (Дашборд)

#### Вариант 1: Classic (Консервативный)
- Чистая структура с четким разделением секций
- Верхняя часть: приветствие и краткая статистика
- Средняя часть: список привычек с чекбоксами
- Нижняя часть: индикатор настроения и быстрое добавление

#### Вариант 2: Crazy (Смелый)
- Круговой прогресс-бар в центре экрана
- Привычки представлены как карточки с анимацией
- Интерактивная временная шкала дня
- Яркие акценты и нестандартные формы

#### Вариант 3: Compromise (Сбалансированный)
- Комбинация карточек и списка
- Индикаторы прогресса виде прогресс-баров
- Минималистичные элементы с акцентом на функциональность
- Легкие анимации при взаимодействии

**Рекомендуемый вариант: Compromise**

#### Структура экрана:
- Шапка: логотип/иконка, приветствие, иконка профиля
- Секция "Сегодня": дата, краткая статистика выполнения
- Секция "Привычки": список привычек с чекбоксами
- Секция "Настроение": индикатор текущего дня
- Плавающая кнопка: быстрое добавление

### 2.2 Экран трекера привычек

#### Основные элементы:
- Фильтры: все/активные/завершенные
- Список привычек с прогресс-барами
- Кнопка добавления новой привычки
- Возможность редактирования привычки

#### Визуальное представление:
- Карточки привычек с иконками
- Прогресс-бар внизу карточки
- Статус: активна/пауза/удалена
- Краткая статистика выполнения

### 2.3 Экран трекера настроения

#### Основные элементы:
- Шкала оценки: от 1 (плохо) до 10 (отлично)
- Эмодзи для визуализации
- Поле для комментария
- Кнопка сохранения

#### Варианты реализации:
- Слайдер с визуальной обратной связью
- Сетка эмодзи для выбора
- Круговая шкала с цветовыми индикаторами

**Рекомендуемый вариант:** Слайдер с эмодзи и цветовой индикацией

### 2.4 Экран статистики

#### Визуализации:
- График выполнения привычек (линейный или столбчатый)
- Календарь настроения (heatmap)
- Круговые диаграммы по категориям
- Сравнение с предыдущими периодами

#### Элементы управления:
- Выбор периода: день/неделя/месяц/год
- Фильтрация по категориям привычек
- Экспорт данных

## 4. Анимации и микровзаимодействия

### 4.1 При взаимодействии с привычкой
- Плавное изменение цвета чекбокса
- Легкая анимация карточки при нажатии
- Краткая всплывающая подсказка

### 4.2 При сохранении настроения
- Анимация выбранного эмодзи
- Появление краткой обратной связи
- Обновление индикатора на главном экране

### 4.3 При достижении цели
- Анимация получения бейджа
- Краткое празднование (confetti effect)
- Обновление статистики в реальном времени

## 5. Адаптивность под разные устройства

### 5.1 Мобильные устройства
- Одностраничный интерфейс с вертикальной прокруткой
- Увеличенные сенсорные области
- Упрощенная навигация

### 5.2 Планшеты
- Возможность двухколоночного макета
- Боковая панель навигации
- Увеличенные элементы для удобства

### 5.3 Десктоп
- Боковая навигационная панель
- Возможность раздельного просмотра
- Расширенные возможности фильтрации
