# Архитектура информационного дизайна и навигация MindSpark

## 1. Общая структура приложения

### 1.1 Основные разделы
1. **Главная/Дашборд** - центральный экран с обзором привычек и настроения
2. **Трекер привычек** - управление и отслеживание привычек
3. **Трекер настроения** - отслеживание эмоционального состояния
4. **Статистика** - графики и аналитика
5. **Достижения** - награды и прогресс
6. **Профиль** - настройки и информация о пользователе

### 1.2 Второстепенные разделы
- Регистрация/Авторизация
- Настройки уведомлений
- Настройки приватности
- Помощь и поддержка
- Дисклеймер

## 2. Информационная архитектура

### 2.1 Главная страница (Дашборд)
- Краткий обзор выполнения привычек за день
- Индикатор настроения текущего дня
- Быстрый доступ к добавлению новой записи настроения
- Календарь настроения (мини-версия)
- Последние достижения
- Быстрое добавление привычки

### 2.2 Трекер привычек
- Список текущих привычек с индикаторами выполнения
- Возможность добавления новых привычек
- Настройка частоты и времени напоминаний
- История выполнения привычки
- Категории привычек (здоровье, работа, личное)

### 2.3 Трекер настроения
- Ежедневная запись настроения
- Шкала оценки (1-10) или эмодзи
- Возможность добавления комментариев
- Просмотр по дням/неделям
- Связь с событиями дня

### 2.4 Статистика
- Графики выполнения привычек
- Календарь настроения (подробный)
- Сравнение периодов
- Статистика по категориям привычек
- Корреляция между привычками и настроением

### 2.5 Достижения
- Система бейджей и уровней
- История получения достижений
- Цели и вызовы
- Сравнение с предыдущими периодами

### 2.6 Профиль
- Личная информация
- Цели и предпочтения
- Настройки уведомлений
- Настройки конфиденциальности
- Статистика аккаунта

## 3. Система навигации

### 3.1 Нижнее навигационное меню (мобильная версия)
- Домой (иконка дома) - Дашборд
- Плюс (иконка плюса) - Быстрое действие (добавить привычку/настроение)
- График (иконка графика) - Статистика
- Звезда (иконка звезды) - Достижения
- Профиль (иконка пользователя) - Профиль

### 3.2 Боковое меню (десктопная версия)
- Главная
- Привычки
- Настроение
- Статистика
- Достижения
- Настройки
- Помощь

### 3.3 Хлебные крошки
Для десктопной версии используются хлебные крошки в верхней части страницы:
Например: Главная → Привычки → Название привычки

## 5. Принципы организации контента

### 5.1 Приоритезация информации
1. **Высокий приоритет**: Состояние привычек на сегодня, текущее настроение
2. **Средний приоритет**: Ближайшие цели, последние достижения
3. **Низкий приоритет**: Историческая статистика, настройки

### 5.2 Группировка элементов
- Функциональная группировка: все, связанное с привычками, в одном разделе
- Частота использования: наиболее часто используемые элементы на главной
- Логическая связь: настроение и статистика связаны между собой

## 6. Пути пользователя

### 6.1 Путь нового пользователя
Регистрация → Онбординг → Установка целей → Выбор начальных привычек → Первое отслеживание настроения → Дашборд

### 6.2 Путь ежедневного использования
Открытие приложения → Просмотр дашборда → Отметка привычек → Отметка настроения → Проверка статистики (опционально)

### 6.3 Путь анализа прогресса
Статистика → Выбор периода → Просмотр графиков → Анализ корреляций → Корректировка привычек
