# Руководство по бренду MindSpark

## 1. Общие принципы бренда

MindSpark - это приложение, которое помогает офисным работникам повышать продуктивность через формирование полезных привычек и отслеживание эмоционального состояния. Наш бренд символизирует момент осознания, вдохновения и личностного роста.

### Ценности бренда:
- **Баланс** - между работой и эмоциональным благополучием
- **Прогресс** - постоянное развитие и улучшение себя
- **Осознанность** - понимание своих эмоций и привычек
- **Простота** - доступный и интуитивно понятный интерфейс

## 2. Логотип

### Описание
Логотип состоит из абстрактной искры, состоящей из двух соединенных кругов, символизирующих баланс между разумом и эмоциями. Это отражает суть приложения - достижение равновесия через осознанность и саморазвитие.

### Версии логотипа
1. **Полноформатный**: графический элемент + текст "MindSpark"
2. **Компактный**: только графический элемент
3. **Текстовый**: только название "MindSpark" в фирменном шрифте

### Цветовые варианты
- **Стандартный**: графический элемент #6366F1, текст #111827
- **Обратный**: графический элемент #6366F1, текст #FFFFFF (для темных фонов)
- **Монохромный**: графический элемент и текст #11827

### Минимальный размер
Минимальный размер логотипа - 24px по наименьшей стороне для обеспечения читаемости.

### Охранное поле
Вокруг логотипа должно быть свободное пространство не менее 1/2 высоты логотипа.

## 3. Цветовая палитра

### Основные цвета
- **MindSpark Blue-Violet**: #6366F1 (основной цвет)
- **Growth Green**: #10B981 (акцентный цвет)
- **Dark Text**: #111827 (основной текст)
- **White**: #FFFFFF (фон, контраст)

### Вспомогательные цвета
- **Light Gray**: #F9FAFB (вторичный фон)
- **Medium Gray**: #6B7280 (вспомогательный текст)
- **Error Red**: #DC2626 (ошибки)
- **Warning Orange**: #F59E0B (предупреждения)
- **Info Blue**: #3B82F6 (информация)

## 4. Типографика

### Основной шрифт
- **Семейство**: Inter
- **Использование**: весь основной контент

### Иерархия текста
- **Заголовки H1**: Inter Semibold, 34px, высота строки 42px
- **Заголовки H2**: Inter Semibold, 30px, высота строки 36px
- **Заголовки H3**: Inter Semibold, 24px, высота строки 32px
- **Основной текст**: Inter Regular, 16px, высота строки 24px
- **Вспомогательный текст**: Inter Medium, 14px, высота строки 20px
- **Мелкий текст**: Inter Medium, 12px, высота строки 16px

## 5. Визуальные элементы

### Кнопки
- **Primary Button**: прямоугольная форма, радиус 8px, цвет #6366F1, текст белый
- **Secondary Button**: прямоугольная форма, радиус 8px, цвет прозрачный, обводка #6366F1
- **Ghost Button**: без фона, только текст

### Карточки
- Радиус скругления: 12px
- Тень: 0 4px 6px rgba(0,0,0,0.05)
- Внутренние отступы: 16px

### Иконки
- Стиль: линейные иконки с толщиной 2px
- Размеры: 16px, 20px, 24px, 32px
- Цвет по умолчанию: #111827

## 6. Темы

### Светлая тема (по умолчанию)
- Основной фон: #FFFFFF
- Фон карточек: #FFFFFF
- Основной текст: #111827

### Темная тема
- Основной фон: #111827
- Фон карточек: #1F2937
- Основной текст: #F9FAFB

## 7. Правила использования

### Запрещено:
- Изменять пропорции логотипа
- Использовать другие цвета для логотипа кроме указанных
- Добавлять тени, градиенты или эффекты к логотипу
- Использовать логотип на фоне, который мешает его восприятию
- Изменять шрифт в логотипе

### Рекомендации:
- Всегда оставлять достаточное охранное поле вокруг логотипа
- Использовать логотип в соответствии с цветовой схемой фона
- При печати использовать монохромную версию при необходимости
