# Дизайн-система для MindSpark

## 1. Общая информация

MindSpark - приложение для повышения продуктивности через формирование привычек и отслеживание эмоций. Целевая аудитория - офисные работники 25-40 лет.

## 2. Цветовая палитра

### Основные цвета
- **Основной цвет:** #6366F1 (фиолетово-синий) - баланс, продуктивность
- **Акцентный цвет:** #10B981 (зеленый) - прогресс, развитие
- **Фоновый цвет:** #FFFFFF - белый с легким оттенком
- **Цвет текста:** #111827 - почти черный
- **Цвет ошибки:** #DC2626 - насыщенный красный
- **Вторичный текст:** #6B7280 - нейтральный серый

### Вспомогательные цвета
- **Фон вторичных элементов:** #F9FAFB - светло-серый
- **Цвет успеха:** #10B981 - зеленый
- **Цвет предупреждения:** #F59E0B - оранжевый
- **Цвет информации:** #3B82F6 - синий

## 3. Типографика

### Шрифты
- **Заголовки:** Inter Semibold
- **Основной текст:** Inter Regular
- **Вспомогательный текст:** Inter Medium

### Иерархия текста
- **H1:** 34px/42px (Inter Semibold)
- **H2:** 30px/36px (Inter Semibold)
- **H3:** 24px/32px (Inter Semibold)
- **Основной текст:** 16px/24px (Inter Regular)
- **Вспомогательный текст:** 14px/20px (Inter Medium)
- **Мелкий текст:** 12px/16px (Inter Medium)

## 4. Сетка и отступы

### Сетка
- 12-колоночная адаптивная сетка
- Брейкпоинты:
  - xs: 0px (до 320px)
  - sm: 640px
  - md: 768px
  - lg: 1024px
  - xl: 1280px
  - 2xl: 1536px

### Отступы
- Базовая единица: 8px
- Маленькие: 4px, 8px
- Средние: 12px, 16px
- Большие: 24px, 32px
- Огромные: 48px, 64px
